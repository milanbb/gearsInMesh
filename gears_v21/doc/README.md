# Live Script guides

After selecting the package root as Current Folder and running `runMeFirst`,
open a guide in MATLAB Live Editor:

```matlab
open(fullfile(pwd,'doc','gearRack_doc.mlx'))
open(fullfile(pwd,'doc','gear_doc.mlx'))
open(fullfile(pwd,'doc','gearsInMesh_doc.mlx'))
```

Run the code sections in order within each guide. The individual-gear guide
clears the workspace. Cached outputs are included as received and have not
been regenerated by this documentation review; rerun sections for current
results. Use class/method help for the complete option reference.

The guides describe rack, gear and pair interfaces. `gear3d` demonstrations
are `.m` scripts in `examples/3d`, with option help in `gear3d.m`.
For graphics export and animation use the Command Window and the supplied
`.m` examples, adding the chosen example folder first. Live Editor export
is not reliable in this release.

No supplementary PDF is required to run these guides. External literature
used by the comparisons is identified in `verification/README.md`.
